What was actually trained

The original conditional MLP is preserved. A second checkpoint starts from those 30,000 updates and runs 12,000 more, dropping the digit condition on 15% of training examples. The same network learns to predict noise with a digit or with an all-zero null condition.

What guidance means here

εguided = εnull + s × (εclass − εnull)

s = 0    null-conditioned model
s = 1    conditional model
s > 1    extrapolation, not certainty

The left pane always uses s = 1. The right uses your selected scale. At s = 1 both must match exactly. Both use the same checkpoint, initial pixels and DDIM time grid. This isolates the guidance change, not training quality. Original checkpoint mode uses s = 1 in both panes because it never learned a null condition. Original DDPM posterior sampling remains in the source; the comparison interface uses DDIM for both checkpoints.

One DDIM step requires one network pass at s = 1, two at other scales. Two panes do not mean equal neural work when guidance is active. Elapsed time shown is local, includes both panes and is not a general hardware benchmark.

Small pixels.
Open process.

196 pixels + 16 sinusoidal time features + 10 class features → 256 SiLU → 256 SiLU → 196 noise predictions. The same 64-step cosine schedule is reused. No U-Net, text encoder, autoencoder, hosted inference or pretrained generator.

MNIST: 28×28 reduced by 2×2 average pooling to 14×14 and scaled to [−1,1]. First 55,000 official training images train; final 5,000 validate. Official test set unused. Raw MNIST files are checked by SHA-256 and not bundled with the website. Validation probes reuse this partition and were monitored, not used to select a checkpoint.

Seed controls initial Gaussian arrays through a 32-bit LCG and Box-Muller. The deterministic time grid rounds a uniform span from t = 63 down to t = 0, with a final clean endpoint. Browser floating-point behavior can cause small differences. Stop preserves only calculated stages, never fabricates completion.

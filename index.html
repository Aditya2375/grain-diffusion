Small, and imperfect.

This model can produce rough, ambiguous or incorrect digits. The requested digit is a learned condition, not a guarantee. There is no text prompt, upscaler, hidden image library or pretrained generator.

Learning to remove
what was added.

Training takes a real handwritten digit, adds a known amount of Gaussian noise, and asks a neural network to predict that noise. Sampling begins with noise alone and reverses the process through 64 steps.

The examples are low-resolution digit-like images, not photographs. No FID, classifier accuracy or perceptual-quality score was measured. Noise-prediction loss below is not an image-quality rating.

The actual training run

Validation uses 12 fresh batches of 256 images from the held-out 5,000 images per checkpoint, with its own fixed random generator. It is a stochastic noise-denoising measurement. Training loss is a rolling mean over 500 updates.

A compact DDPM

Each 28×28 MNIST image is reduced by 2×2 average pooling to 14×14, then scaled to [−1,1]. The denoiser is an MLP: 196 pixels + 16 sinusoidal timestep features + 10 one-hot class features → 256 SiLU → 256 SiLU → 196 noise predictions. A 64 step cosine variance schedule is used. At sampling, predicted clean pixels are clipped to [−1,1] before the posterior update.

This is a conditional pixel-space DDPM learning the original noise-prediction objective. It does not use a U-Net, latent autoencoder, text encoder or classifier-free guidance. The compact MLP and short training run limit quality.

Data and source

MNIST, via the CVDF mirror: handwritten digit data created by Yann LeCun, Corinna Cortes and Christopher J.C. Burges. 55,000 training images, final 5,000 of the official 60,000 training images held out for validation. The official test set was not used or scored. Raw data are not bundled in this app.

Method: Ho, Jain & Abbeel, Denoising Diffusion Probabilistic Models (2020). This small experiment does not reproduce their architecture, benchmarks or reported image quality.
